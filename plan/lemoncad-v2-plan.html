LemonCAD

Working name, not finalized · 25 September 2026 · Supersedes revision 1 where scope differs.

1. Summary

Anyone can open a model, measure it, and download a PNG or PDF without logging in. A free account adds persistent drafts, sharing, and drawings. Paid users can commission weld/check fixture design and fabrication costing from the same project. Reuse the inspected Bixl Studio geometry and viewer work, and adapt existing engineering skills into web workflows.

4. Anonymous viewer requirements

  • Drop/browse STEP/STP or STL; progress, cancellation, useful import errors, fit and standard views, pan/orbit/zoom.
  • Proposed first supported workload: single STEP parts; reject unsupported assemblies clearly rather than displaying an incomplete part.
  • Show units and overall size in an explicit part frame. Confirm STL units before measurements.
  • Initial dimensions: supported cylindrical diameter/radius, parallel planar separation, and supported point/feature distance. Centre-to-centre and angles require their own reference tests before exposure.
  • Highlight selected geometry; add, remove, undo and reposition dimension labels. Changing camera or mesh quality must not alter CAD-derived values.
  • PNG/PDF includes current view, visible dimensions, units, source filename and measurement basis. Preview exports; avoid clipped labels. No login gate on export.
  • Temporary anonymous processing does not create a saved draft. Explicit Save after login promotes the current session to a private project.
Changed privacy assumption: Bixl's viewer posts STEP files to a backend; CAD endpoints create temporary files and remove them in request cleanup. This is evidence of server processing, not a complete retention guarantee. Specify session expiry, error/crash cleanup and logging behavior before launch; do not claim files never leave the device.

9. Release gates

  • Accuracy: supported measurements agree with known CAD values within a numerical tolerance agreed before launch. CAD-derived values are independent of tessellation and camera. Mesh-derived values remain labeled.
  • Persistence: save → logout → reopen restores source, view, dimensions and drawings. Invalid anchors on changed geometry are surfaced, never silently reassigned.
  • Sharing: other users cannot access private drafts; links expose only the published revision; revocation blocks subsequent server access. Previously downloaded copies cannot be recalled.
  • Drawing: show all declared omissions, correct units/material assumptions and export only current reviewed settings. No unsupported feature is presented as checked.
  • Public processing: isolate new service from Bixl production; enforce upload/work limits, timeouts, cancellation and cleanup. Paid jobs must not starve free viewing.
  • Entitlements: anonymous export stays open; save/share requires login; paid APIs verify entitlement server-side.
  • Fixture: preserve datum and concept gates and distinguish CAD verification, fabrication readiness, calibration and inspection validation.
  • Costing: calculator succeeds and totals reconcile; assumptions and unpriced items stay visible; customer-specific rates never leak.
  • Usability: proposed pilot target remains 8/10 representative users able to import, measure and export a specified sample unaided within two minutes.

11. Measures and non-goals

Track successful import → measurement → export; export → account creation → first saved draft; reopened drafts; shared views; drawing completion; paid job starts, purchases, delivered outcomes and margin after compute/review time. Exclude model content, file names, dimensions and rates from analytics.

  • No native SolidWorks/Inventor importer, general CAD editing or large-assembly promise in initial release.
  • No automatic formal drawing release, inferred tolerances, or unreviewed manufacturing approval.
  • No live collaborative editing or recipient editing in first sharing release.
  • No migration of Bixl accounts, production data, branding or private rates into the new public site.

12. Open decisions

  1. Confirm separate LemonCAD product with reuse of Bixl code, rather than adding public access to Bixl Studio.
  2. Confirm server-side STEP processing and publish retention rules; browser-only processing would be additional work.
  3. Share-link audience, raw-file download policy and expiry; proposed default is read-only snapshot links without recipient login.
  4. Accuracy tolerance, supported part families, file/compute/storage limits and performance benchmarks.
  5. Paid launch order, pricing, included revisions, review responsibility and approved public costing-rate sources.
